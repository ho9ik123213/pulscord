# 🚀 Быстрый старт Pulscord

Добро пожаловать в мессенджер **Pulscord**! Это руководство поможет вам быстро начать работу.

## ⚡ Самый быстрый способ запуска

### Вариант 1: VS Code + Live Server (рекомендуется)

1. **Откройте папку в VS Code:**
   - Меню → File → Open Folder
   - Выберите папку `Pulscord`

2. **Установите расширение Live Server:**
   - Ctrl+Shift+X (Extensions)
   - Поиск: "Live Server"
   - Установите от Ritwick Dey

3. **Запустите сервер:**
   - Правый клик на `index.html`
   - Выберите "Open with Live Server"
   - Браузер откроется автоматически

### Вариант 2: Python (встроено в систему)

```bash
# Откройте командную строку/терминал в папке Pulscord

# Windows
python -m http.server 8000

# macOS/Linux
python3 -m http.server 8000

# Откройте в браузере:
# http://localhost:8000
```

### Вариант 3: Node.js

```bash
# Установите http-server один раз
npm install -g http-server

# Запустите в папке проекта
http-server . -p 8000

# Откройте http://localhost:8000
```

## 🎯 Первые шаги в приложении

### 1. Просмотр сообщений
- Приложение откроется на канале **#общее**

- Доступные пользователи:
  - 👤 Алексей (модератор)
  - 👤 Мария
  - 👤 Иван
  - 👤 Елена

### 5. Переключение серверов

- O, Д, П - другие серверы
- \+ - добавить новый сервер

## 🎨 Персонализация

### Добавить новый канал
1. Откройте файл `app.js` в текстовом редакторе
2. Найдите строку: `channels: {`
3. Добавьте новый канал:
```javascript
'my-channel': { 
    name: 'мой-канал', 
    description: 'Описание канала',
    icon: '#' 
}
```

### Изменить цвета темы
1. Откройте файл `styles.css`
2. В начале файла найдите раздел `:root {`
3. Измените цвета:
```css
--primary-color: #5865f2;  /* Измените цвет */
--text-primary: #dcddde;   /* Измените цвет текста */
/* и т.д. */
```

### Добавить нового пользователя
1. Откройте файл `app.js`
2. Найдите раздел: `users: {`
3. Добавьте пользователя:
```javascript
'user-5': { 
    name: 'Имя пользователя', 
    role: 'Роль',
    avatar: 'И',  /* Первая буква имени */
    status: 'online'  /* online / offline */
}
```
4. Добавьте его в HTML (в разделе ПРЯМЫЕ СООБЩЕНИЯ)

## 🐛 Решение проблем

### Приложение не загружается
```
1. Убедитесь, что все файлы в одной папке
2. Проверьте консоль браузера (F12 → Console)
3. Переубедитесь, что сервер работает на порту 8000
```

### Сообщения не сохраняются
```
1. Это демо-версия - сообщения хранятся только в памяти
2. Для постоянного хранения нужна база данных (MongoDB, Firebase)
3. При перезагрузке страницы сообщения загрузятся из LocalStorage
```

### Стили применяются неправильно
```
1. Очистите кэш браузера (Ctrl+Shift+Del)
2. Убедитесь, что styles.css находится в той же папке
3. Перезагрузите страницу (F5)
```

### JavaScript не работает
```
1. Проверьте консоль браузера на ошибки (F12)
2. Убедитесь, что app.js подключен в index.html
3. Проверьте права доступа к файлам
```

## ❓ Часто задаваемые вопросы

**Q: Как подключить реальную БД?**
A: Требуется бэкенд. Используйте Node.js + Express + MongoDB или Firebase.

**Q: Могу ли я добавить больше серверов?**
A: Да, отредактируйте `APP_CONFIG.servers` в `app.js`.

**Q: Как сделать приложение доступным в интернете?**
A: Загрузите на хостинг (Netlify, Vercel, GitHub Pages).

**Q: Поддерживается ли мобильная версия?**
A: Да! Дизайн адаптивен для всех устройств.
