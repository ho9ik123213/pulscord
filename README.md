# 🎯 Pulscord - Мессенджер

Полнофункциональный мессенджер с интерфейсом, похожим на Discord. Приложение разработано на HTML, CSS и JavaScript с полной русификацией.

- 🌐 **Русский интерфейс** - полная локализация на русском языке
- 📱 **Адаптивный дизайн** - работает на всех устройствах
- 💬 **Система сообщений** - отправка и просмотр сообщений
- 👥 **Управление контактами** - прямые сообщения и каналы
- 🎯 **Интерактивная панель** - полная интерактивность в реальном времени

## 🚀 Как запустить

### Capacitor: Android и iOS

Pulscord использует текущий HTML/CSS/JS-клиент внутри Capacitor. Node-сервер запускается отдельно и должен быть доступен телефону по LAN.

```bash
npm install
npm run start
npx cap add android
npm run cap:sync
npm run cap:android
```

Для iOS нужна macOS с Xcode:

```bash
npx cap add ios
npm run cap:sync
npm run cap:ios
```

По умолчанию мобильный клиент обращается к `http://192.168.3.6:3000`. Для другого адреса API задайте его перед запуском в консоли приложения:

```js
localStorage.setItem('pulscord_api_url', 'http://АДРЕС_КОМПЬЮТЕРА:3000');
```

### Tauri: desktop

Для Tauri нужны Rust и системные зависимости Tauri. В dev-режиме backend запускается командой из `src-tauri/tauri.conf.json`.

```bash
npm install
npm run tauri:dev
npm run tauri:build
```

Конфигурация Tauri находится в `src-tauri/`, а Capacitor -- в `capacitor.config.ts`.

### Быстрый запуск (без установки)

1. Откройте папку `Pulscord` в VS Code
2. Установите расширение "Live Server"
3. Кликните правой кнопкой на `index.html` → "Open with Live Server"

### Через встроенный сервер Python

```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000
```

Затем откройте http://localhost:8000 в браузере.

### Через http-server (Node.js)

```bash
# Установите http-server
npm install -g http-server

# Запустите сервер
http-server . -p 8000
```

Откройте http://localhost:8000 в браузере.

## 🎮 Использование

### Основные функции

#### Навигация по серверам
- Нажмите на значок сервера в левой боковой панели
- "Главная" - стартовая страница
- Кликните "+" чтобы добавить новый сервер

#### Просмотр каналов
- Выберите сервер
- Кликните на канал в списке (в левой боковой панели)
- Введите сообщение и нажмите Enter

#### Прямые сообщения
- Кликните на пользователя в списке "ПРЯМЫЕ СООБЩЕНИЯ"
- Отправьте сообщение в чат
- Используйте "+" чтобы начать новый разговор

#### Отправка сообщений
1. Кликните в поле ввода
2. Напишите сообщение
3. Нажмите **Enter** или кликните кнопку отправки ✈️

### Доступные каналы

- **#общее** - основной канал для обсуждения
- **#объявления** - важные объявления
- **#случайное** - случайные темы и развлечения
- **#события** - события и мероприятия

## 🎨 Кастомизация

### Изменение цветов темы

Отредактируйте переменные в `styles.css`:

```css
:root {
    --primary-color: #5865f2;        /* Основной цвет (синий) */
    --text-primary: #dcddde;         /* Основной текст */
    --background-primary: #36393f;   /* Основной фон */
    /* ... другие цвета */
}
```

### Добавление новых каналов

В файле `app.js` отредактируйте объект `APP_CONFIG.channels`:

```javascript
'channel-id': { 
    name: 'название', 
    description: 'описание', 
    icon: '#' 
}
```

### Добавление новых пользователей

В файле `app.js` отредактируйте объект `APP_CONFIG.users`:

```javascript
'user-id': { 
    name: 'Имя', 
    role: 'Роль', 
    avatar: 'И', 
    status: 'online' 
}
```
