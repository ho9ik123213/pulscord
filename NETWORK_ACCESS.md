# 🌐 Подключение к Pulscord с других устройств

## Как подключиться с другого компьютера/телефона

### Способ 1: Через локальный IP (рекомендуется)

1. **Узнайте IP адрес вашего компьютера**
   - Откройте терминал/PowerShell
   - Выполните: `ipconfig` (Windows) или `ifconfig` (Mac/Linux)
   - Найдите строку "IPv4 Address:" - это ваш IP (например: 192.168.1.100)

2. **Откройте приложение на другом устройстве**
   - В браузере введите: `http://ВАШ_IP:3000`
   - Например: `http://192.168.1.100:3000`

3. **Авторизуйтесь**
   - Используйте те же учетные данные
   - Или создайте новый аккаунт

### Способ 2: Через имя хоста

Если способ 1 не работает, попробуйте:
```
http://ИМЯКОМПЬЮТЕРА:3000
```

Имя компьютера обычно видно в параметрах Windows.

## ❓ Решение проблем

### Приложение не загружается
```
✗ Проверьте, что оба устройства в одной сети (Wi-Fi)
✗ Проверьте брандмауэр Windows (может блокировать порт 3000)
✗ Попробуйте подключиться через конкретный IP вместо localhost
```

### Брандмауэр Windows

Если вы видите ошибку подключения:

1. Откройте Брандмауэр Defender
2. Нажмите "Разрешить приложению..."
3. Нажмите "Изменить параметры"
4. Нажмите "Разрешить еще одно приложение"
5. Найдите `node.exe` и добавьте его
6. Выберите "Частная сеть"
7. Нажмите "Добавить"

Или используйте PowerShell от администратора:
```powershell
New-NetFirewallRule -DisplayName "Node.js Server" -Direction Inbound -Action Allow -Protocol TCP -LocalPort 3000
```

### Проверка подключения

Убедитесь, что:
- ✓ Оба устройства подключены к одной сети
- ✓ Порт 3000 доступен (не заблокирован брандмауэром)
- ✓ Сервер запущен (`node server.js`)
- ✓ IP адрес правильный

## 📱 Доступ с мобильного телефона

1. Подключитесь к той же Wi-Fi сети
2. Откройте браузер (Chrome, Safari, Firefox)
3. Введите: `http://192.168.1.100:3000` (замените на ваш IP)
4. Приложение полностью адаптивно для мобильных!

## 🔒 Безопасность

⚠️ **Внимание:** Это локальная сеть, данные передаются без шифрования.

Для использования в интернете требуется:
- SSL сертификат (HTTPS)
- Развертывание на сервере (Heroku, Vercel, AWS и т.д.)
- Настройка безопасности

## 🌍 Развертывание в интернет

Чтобы приложение было доступно из интернета:

1. Разверните на облачном сервере (Heroku, Vercel, Railway)
2. Используйте HTTPS (Let's Encrypt - бесплатно)
3. Настройте переменные окружения
4. Используйте настоящую БД (MongoDB Atlas вместо JSON файлов)
